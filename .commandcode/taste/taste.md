# Taste

## Workflow
- Prefers implementation executed progressively, stage by stage, from the first stage through to completion, rather than in a single big-bang pass. Confidence: 0.7
- Prefers to review/approve a written implementation plan before code is written (plan-first). Confidence: 0.7
